# lvextend

`lvextend` - Add space to a logical volume

See also: [volumes](volumes.md), [`vgextend`](vgextend.md)

## Introduction

`lvextend` grows an existing logical volume (LV) by pulling from the free space in its volume group which was added by `vgextend`.

See [`vgextend`](vgextend.md) for an example.
