# loginctl

`loginctl` - Control the systemd login manager

See also: [`systemd`](systemd.md)

## Introduction
`loginctl` is a command-line utility that's part of `systemd`, used to inspect and manage user logins, sessions, and seats on a Linux system.

```bash
loginctl list-sessions  # show all active sessions
loginctl list-users     # show all logged-in users
```
