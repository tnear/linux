# type

`type` - write a description of command type

## Basic usage

```bash
# alias
$ type ls
ls is an alias for ls --color=auto

# command
$ type mv
mv is /usr/bin/mv

# shell builtin
$ type jobs
jobs is a shell builtin

# user-defined functions
$ type my_fcn
my_fcn is a shell function from /home/user/.zshrc
```
